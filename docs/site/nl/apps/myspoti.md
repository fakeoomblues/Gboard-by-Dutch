# Myspoti

**Appversie:** 2.3.0 · **Build:** 1121 · **Origineel bestand:** APK

[Gebruik je originele APK](../guides/downloads.md#local-original-inputs){ .md-button .md-button--primary }

Selecteer de door de uitgever ondertekende Myspoti-APK. Versie 2.2.0, build 1116, wordt ook ondersteund. Myspoti wordt ontwikkeld door [kota-zo/myspoti](https://github.com/kota-zo/myspoti).

## Patches

| Patch | Standaard | Wat verandert er? |
| --- | --- | --- |
| **Gearslip personal library** | Aan | Laat de ingestelde Gearslip-host de bestaande Home, bibliotheek en downloads van Myspoti bekijken, zoeken en muziek kiezen om af te spelen. |

## Advertentie- en trackingdiensten

Deze compatibiliteitspatch verandert de toegang tot de muziekbrowser. De patch verwijdert geen onlinediensten, levert geen account en verandert geen abonnementsrechten.

## Voor gebruik

Log in bij Myspoti. De optie voor vertrouwde hosts gebruikt standaard het officiële Gearslip-pakket. Voeg alleen een ander hostpakket toe voor een versie die je bewust gebruikt.

De gebruiker heeft bevestigd dat de patch met Myspoti 2.2.0 in Gearslip werkt en heeft de stabiele release goedgekeurd. Het exacte originele 2.3.0-bestand kan op de desktop worden gepatcht; een gemelde archiefleesfout in Manager wordt nog onderzocht. Gebruik 2.2.0 of patch 2.3.0 op de desktop als Manager het bestand niet kan lezen. Een gepatchte APK moet opnieuw worden ondertekend. De door de uitgever ondertekende installatie kan niet met een andere sleutel worden bijgewerkt. Bewaar deze tijdens het testen van een aparte kopie; verwijder de installatie niet alleen om deze patch te proberen.

# Myspoti

**App version:** 2.3.0 · **Build:** 1121 · **Original file:** APK

[Use your original APK](../guides/downloads.md#local-original-inputs){ .md-button .md-button--primary }

Select the publisher-signed Myspoti APK. Version 2.2.0, build 1116, is also supported. Myspoti is developed by [kota-zo/myspoti](https://github.com/kota-zo/myspoti).

## Patches

| Patch | Default | What it does |
| --- | --- | --- |
| **Gearslip personal library** | On | Lets the configured Gearslip host browse Myspoti's existing Home, Library and Downloads, use search and select music for playback. |

## Advertising and tracking services

This compatibility patch changes browser access. It does not remove online services, supply an account or change subscription access.

## Before using

Sign in to Myspoti. The trusted-host option defaults to the official Gearslip package. Add another host package only for a build you intentionally use.

The user confirmed that the patch works with Myspoti 2.2.0 in Gearslip and approved its stable release. The exact publisher 2.3.0 input passes desktop patching; a reported Manager archive-read error remains under investigation. Use 2.2.0 or patch 2.3.0 on desktop if Manager cannot read it. A patched APK must be signed again. The publisher-signed installation cannot be updated using a different signing key. Keep it while testing a separate copy; do not uninstall it just to try this patch.

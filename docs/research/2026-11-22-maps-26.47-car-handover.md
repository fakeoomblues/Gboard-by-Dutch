# Maps 26.47 car adapter — engineering handover

State at handover: the patch set applies cleanly to `26.47.00.1022347503` (1068892333), the phone app runs,
and the native car adapter now gets as far as `onAppResume`. This document records the method that
*must* be used for the remaining work, everything resolved so far with its evidence, every fix, and the
open items.

## 1. The rule that matters

**Never resolve a Maps type, field or method by its obfuscated name.** Every 26.44 name still exists in
26.47 attached to a different object, so a name match succeeds and binds the wrong thing. Verified:

```
Lblvb;  route model (26.44)  -> now an Enum with 3 methods
Lycj;   route path  (26.44)  -> now 67 methods
Lcizm;  distance unit (26.44) -> now a proto message (extends Lcnod;)
Lbmxs;  native manager        -> now an unrelated 7-method class
Llvp;   navigation binder     -> now an unrelated 2-method class
```

Resolve by **shape**: search the build for the signature/fields the object must have, then verify the
resolution on both APKs. Useful probes (throwaway Java in `$TMPDIR/re`, compiled against the patcher jar
`$TMPDIR/re/cm`):

- `SigScan apk name [params…] [->ret]` — classes declaring a method with that exact signature.
- `EnumC apk [name]` — methods `c(X)X` with an enum X.
- `Where apk Ltype;` — which dex defines a class and how many methods.
- `InstrAt apk class name params ret index` — one instruction with register fields.
- `CU apk class name params ret from to` — instructions with code-unit offsets (branch targets).
- `GuardScan apk` — our `Shapes.HIDE_*` guards whose register is later used as a reference.
- `VoiceHash apk refs.txt` — the `mapsVoiceFingerprint` hash for contract tables.
- `Abi apk interface jobClass` — one-argument method coverage across implementers.
- `DexDump apk Ltype; [method]` — fields, methods, or one method body (the workhorse).

## 5. How to continue

1. Reproduce with the host, then read `logcat -d | grep -A20 MapsNativeCar` *immediately*: the main ring
   buffer is 256 KiB and rotates in minutes, and our host-visible message now carries the cause.
2. For any name in a stack trace, do not search for that name — search for the shape: `SigScan` for the
   method, field-scan for a field of the required type, `Where` for the class.
3. Verify every resolution on both APKs before changing the extension, and add the row to the table in
   §2.
4. Keep the invariant: no extension code may compare an obfuscated class name. Compare `instanceof`,
   signatures, or field types.

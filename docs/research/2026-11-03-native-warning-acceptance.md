`WarningScheduler` is wired into both receivers: grants precede speaker calls, renewals run every two seconds, queued revisions retain original authority deadlines, and uncertain output remains fenced. `WarningPreferences` preserves explicit old mute/category/chime choices and requires first-use review. Map-pin settings remain separate from audible categories. Multiple current native messages can use the existing phone/car compact surfaces; visual inspection remains required.

The native model record is `tests/fixtures/navigation-warnings/flitsmeister-model-verification.json`. Runtime observations and limitations are in `tests/fixtures/navigation-warnings/runtime-spikes.json` and the [runtime report](2026-11-02-native-warning-runtime-spikes.md). Model counts are synthetic accepted adapter calls through real models/resources, not upstream detections.

Real Maps testing found native focus could interrupt an owned warning before final media dispatch. Real-route P0 cancellation succeeded, then regeneration exposed a subclass field shadowing the base route field. Source fixes and regressions exist; previous output success does not prove those fixes.

The user currently authorizes emulator testing. The brief USB check read Android version and package paths only; no phone install, permission/app-data change or instrumentation occurred. Use the owned `native_warnings_api34` emulator until explicitly instructed otherwise. Physical/car acceptance remains unproved.

Green component tests, a manifest row, rebuilt APK or synthetic audible sample alone cannot establish complete spoken warning support.

Parked controls are implemented: preview uses an authenticated source-created, explicitly labelled synthetic authority and the normal durable playback grant; it does not create a detector/public road report and never replays without the local manual request. Recovery opens a private source-owned Activity through a verified immutable PendingIntent, requires explicit parked/stopped confirmation, refuses a ready owner, and revokes old announcement authority before allowing future warnings. UI/runtime acceptance remains pending.

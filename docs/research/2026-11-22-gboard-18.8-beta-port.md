## 2. Toolchain (reusable)

Everything lives in `.tools/artifacts/gboard-port-18.8.0-beta/` and
`~/Scripts/gboard/port/`:

| Tool | Purpose |
| --- | --- |
| `Mapper.java` | Structural class/member mapper between two builds (string anchors → super/interface propagation → body-position unification → shape uniqueness; then member voting by exact body position) |
| `SearchMember.java` | Find every class declaring a method with an exact descriptor (`(IZ)Z` …) — used to recover classes the mapper mis-attributes |
| `FindClass.java` | Dump fields/methods/strings of a class from the APK |
| `MethodShape.java` | Register count, instruction count, return opcodes, try blocks and written fields of one method — required by the stock-shape guards |
| `Fingerprint.java` | Byte-exact reimplementation of `gboardStructuralFingerprint()`; verified by reproducing the two known 18.6.3 Custom Theme hashes |
| `Validate.java` | Re-checks all 244 bindings against an APK and prints renames |
| `port.py` | Extracts/rewrites hard-coded descriptors in the patch sources |
| `portbindings.py` | Parses/regenerates `GboardVersionBindings.kt` |
| `fieldpass.py` | Second pass for `Gboard*FieldTarget(classType/name/type)` member renames |

Run order: `Mapper old.apk new.apk classmap.txt queries.txt resolved.txt` →
`port.py rewrite` → `fieldpass.py` → `portbindings.py regen`.

## 6. Remaining six (exact blockers)

| Patch | Blocker | What is needed |
| --- | --- | --- |
| **Enable OCR / Scan Text** | `Could not find Lxws;->c(Lytk;)Lzdv;` | The 15-target OCR preflight (`GboardOcrPatchTargets.preflight`) mixes MLKit-bundled classes with Gboard module-manager classes; the mapper bound several module classes to unrelated 18.8.0 classes (`Lxws;` is now a listener, `Lxws;->a([Lxns;)Lzdv;` is the real request). Needs a per-target re-derivation; the feature was already unshipped in 18.6.3. |
| **Parakeet voice typing** | `m()[B depends on the Lite recognizer` | `ParakeetVoiceTypingPatch.resolveContract` found a recognizer whose `m()[B` belongs to the Lite path; 18.8.0 re-split standard vs Lite recognizers (`jetson_lite_*` flags). Needs a contract re-check, not a rename. |
| **Parakeet personal dictionary** | depends on the above | unblocks with it |
| **Rambler contact names** | `Expected one voice correction list import, found 0` | The discovery keys on "method reads a static field of `VoiceCorrectionListFragment` **and** calls `ModuleManager.getInstance`". In 18.8.0 the add path moved into an anonymous `di` listener (`add_voice_correction_word`) that builds the stats store via `akof.n(aknd.MUSE_STATS, akjx.class, …)` — no `ModuleManager` call in the same method. Needs a new discovery anchor (the `"USER_ADDED"` literal and the `akof.n(MUSE_STATS, …)` shape). |
| **Toolbar Editing Buttons** | `Could not find Laadr;->m()Laaej;` | `AccessPoint.m()` now returns the abstract builder `Laadm;`; the descriptor setters moved from `q(Runnable)`/`i(I)` to `i(Laubj;)`/`l(I)` (AutoValue builder, icon setter is the one writing field `r`). This is an API change in the injected call sequence, not a rename. |
| **Web Clipboard** | `Lafae;->onCreate()V v9 liveness anchor drifted` | The capture bootstrap requires `v9`'s last use to match `isExactLastSavedLocalUse()`. Register allocation changed in 18.8.0's `onCreate`; either a different scratch register satisfies the liveness proof or the anchor must be re-derived. |

All six fail closed with a precise message, so a partial bundle is safe: the other 20 apply
and the APK is signed.

## 8. Limits

- Patch **application** is verified; no feature was run on a device. Native payloads (OCR
  engine, Rambler/Parakeet recognizers) are untouched and per-ABI.
- Only arm64 was patched. The arm32 APK has the same dex obfuscation map (release builds
  share it), but the `parity` claim is unverified for 18.8.0: run the same command with the
  v7a APK and compare `failedPatches`.
- The 18.6.3 target is removed from `Compatibility.kt`; publishing both requires splitting
  `GboardVersionBindings` per version.
- `16` unused bindings still carry 18.6.3 values (marked `PORT-18.8`); they do not affect
  patching today but must not be trusted for new work.
- Settings screenshots/menus were not re-checked; the About-page and settings-text patches
  depend on resource ids that this beta renumbered (`0x7f14…`).

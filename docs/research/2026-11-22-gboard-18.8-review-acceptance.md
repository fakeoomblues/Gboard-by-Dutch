## Writing Tools (was P1) — scope narrowed, not faked

18.8 builds the routed intent set from the flag
`voice_command_intent_types_routed_to_writing_tools_v2` (`aeam.f`, an `adgn` whose value is a `basg`)
and classifies with `ohu.a(oig)`. 18.6.3's route-set builder (`wgv.h(Object)`) does not exist, and
`vow` exposes `h()Z`, so the old `INTENT_AUTO_FIX` insertion cannot be emitted. The acceptance shim
returns immediately on the 18.8 binding.

The public patch therefore no longer depends on `gboardAiWritingTools1863AutoFixAcceptancePatch`, its
unused import is gone, and its description no longer promises proofread/Auto Fix. Rewrite and tone
are still wired through the flag patch. Porting Auto Fix means building the 18.8 intent set, which is
a separate task.

## Toolbar menu shim (was P2) — outside the supported set

`access_points_menu_style` is removed from `GboardContributionWiring`, with the reason in place: the
18.5.x shim binds `Laajh;->k(Lxno;)V` (18.8 defines `k(Laacw;)V`) and calls its helper on `Lnib;`
though the helper is installed on `Laajh;`. The public Toolbar Editing Buttons path and its corrected
`aagb` cast are untouched.

## Hidden Flags (was P2) — one Off contract

- Toggle time writes the preference, reads it back, applies the override and logs
  `Hidden flag switch did not take: …` when any step disagrees.
- Startup now reapplies **every configured entry**, not only the enabled ones, so Off stays an
  explicit `false` across a process restart. Flags never touched keep Gboard's stock value.
- What remains unproven: the effect on the live consumer, per flag, which needs the device.

## Documentation corrected (was P2)

- `scripts/EmittedParameterCasts.java` and `scripts/EmittedMissingClassRefs.java` now declare classes
  whose names match their files, so the documented `javac`/`java` lines work.
- The handover now says the cast scan does not track register contents, undercounts wide parameter
  slots and prints only the first 12 details; the missing-class scan resolves owners only; the source
  audit reads the canonical repo's map and misses inline strings and reflection constants;
  `ValidateDex` is register capacity, not types or ART loading; the persistence line is an emulator
  run; the Beta-features UI dump is not in the port note.
- Function notes: `mfw` is `implements avti` with ctor `(Context, Delight5Facilitator, mfc, agrh,
  List, int)`; `mhy` implements `mfc`. Port note: the "only arm64 was patched" line is scoped to the
  early runs.
